# Test Kit — feedback despre adoptarea în J1

## Pe scurt

Nu este înregistrată o lacună activă de adoptare Test Kit specifică J1. J1
consumă JAR-ul Test Kit selectat și păstrează verificările de clasificare,
lifecycle și retenție a valorilor în guvernanța și testele locale.

## Înregistrează o problemă de adoptare

Reprodu problema în cel mai mic test J1 afectat. Include coordonata și versiunea
Test Kit, comportamentul așteptat și observat și raportul sau diagnosticul
relevant. [Ghidul Test Kit](../../lib/README.TestKit.md) descrie suprafața
publicată folosită de acest reactor.
