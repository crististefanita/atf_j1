# Test Kit — J1 adoption feedback

## At a glance

No active J1-specific Test Kit adoption gap is currently recorded. J1 consumes
the selected Test Kit JAR and keeps its classification, lifecycle, and value
retention checks in local governance and consumer tests.

## Record an adoption issue

Reproduce the issue in the smallest affected J1 test. Include the Test Kit
coordinate and version, expected and observed behavior, and relevant report or
diagnostic. The [Test Kit guide](../../lib/README.TestKit.md) describes the
published surface used by this reactor.
